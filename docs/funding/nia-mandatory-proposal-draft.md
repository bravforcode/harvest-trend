## 3. สรุปโครงการ (ร่างสำหรับกรอกฟอร์ม)

**ชื่อโครงการ (ร่าง):** แพลตฟอร์มรู้ทันราคาและจังหวะการเก็บเกี่ยวสำหรับพืชเศรษฐกิจ (Harvest Trend — รู้ทันราคา)

**ปัญหา:** เกษตรกรขายผลผลิตโดยไม่มีข้อมูลราคาที่เทียบได้และทันเวลา ราคาหน้าไร่กับราคาตลาดต่างกันมาก ทำให้ขายผิดจังหวะ ข้อมูลราคาอยู่ในหลายแหล่ง (ธปท., data.go.th, สำนักงานเศรษฐกิจการเกษตร) และไม่อยู่ในรูปที่เกษตรกรใช้ตัดสินใจได้

**นวัตกรรม:** ชุดข้อมูลราคาจากหน่วยงานรัฐ รวมเป็นคะแนนสถานะราคาแบบอธิบายได้ (ตาม 4 ปัจจัยที่ระบบคำนวณ: แนวโน้มราคา 40%, อุปทานตามฤดูกาล 25%, จังหวะการเก็บเกี่ยว 20%, สภาพอากาศ 15%) ส่งผ่านเว็บแอป (PWA) และ LINE OA

**ตลาดเป้าหมาย:** เกษตรกรรายย่อยและสหกรณ์ในพื้นที่นำร่อง และผู้ค้าผลผลิตที่ต้องการข้อมูลราคาประกอบการตัดสินใจ

**สถานะปัจจุบัน (ต้องแจ้งตามจริงในข้อเสนอ):**
- ระบบใช้งานได้ บันทึกข้อมูลผ่าน Supabase และส่งแจ้งเตือนผ่าน LINE และ Web Push
- ข้อมูลราคาจริงมาจาก data.go.th และ ธปท. (เฉพาะบางชุด)
- **ข้อมูลจังหวัดและพืชส่วนใหญ่ยังเป็นข้อมูลจำลอง (mock)** ต้องระบุชัดเจนในข้อเสนอและแผนงาน
- **มีข้อบกพร่องที่ต้องแก้ก่อนทดสอบภาคสนาม:** ค่าสภาพอากาศใน `engine.ts` (บรรทัด 137–138) ถูกสุ่มจากเมล็ดที่ผูกกับจังหวัดและพืช ไม่ได้มาจากข้อมูลอากาศจริง

**ผลลัพธ์ที่วัดได้ (KPI เสนอ — ตัวเลขเป็นสมมติฐาน):**
- ผู้ใช้งานที่ใช้งานจริงในพื้นที่นำร่อง (จำนวนจะกำหนดหลังทดสอบกับสหกรณ์)
- จำนวนพืชและจังหวัดที่ใช้ข้อมูลจริง (ไม่ใช่จำลอง) ตามเป้า
- การทดสอบ verdict เทียบกับราคาที่เกิดขึ้นจริงย้อนหลัง (backtest) และรายงานความแม่นยำ
- มูลค่าทางเศรษฐกิจ: เกษตรกรขายได้ราคาสูงขึ้นหรือลดการขายผิดจังหวะ (ต้องวัดด้วย baseline ที่กำหนดไว้ก่อนทดสอบ)

## 5. งบประมาณ (ร่าง — ทุกบรรทัดเป็นสมมติฐาน)

สมมติให้มูลค่าโครงการรวม **4,000,000 บาท** (ค่านี้ต้องปรับตามงานจริง)

| รายการ | สมมติฐาน (บาท) | หมายเหตุ |
|---|---:|---|
| 1. ค่าบุคลากร (พัฒนา/ข้อมูล 1 คน × 12 เดือน + ค่าลงพื้นที่) | 1,600,000 | ต้องคำนวณตามเกณฑ์ค่าแรงของ NIA |
| 2. โครงสร้างพื้นฐานและข้อมูล (Supabase, Vercel, LINE OA, ค่าโดเมน) | 260,000 | ใบเสร็จจริงเก็บไว้ |
| 3. ทดสอบภาคสนาม (สหกรณ์ 2–3 แห่ง, ค่าเดินทาง, ค่าตอบแทนผู้ให้ข้อมูล) | 800,000 | |
| 4. ทดสอบตลาดและการตลาด | 500,000 | |
| 5. ที่ปรึกษาด้านการเกษตรและเศรษฐกิจการเกษตร | 360,000 | ตรวจสอบ verdict และ KPI |
| 6. ทรัพย์สินทางปัญญา กฎหมาย และบัญชี | 240,000 | ผูกกับการโอน IP ของบริษัท |
| 7. บริหารโครงการและค่าสำรอง | 240,000 | |
| **รวม** | **4,000,000** | |

การแบ่งสัดส่วน (ตามเกณฑ์ Thematic ≤75%):
- NIA สนับสนุนสูงสุด 75% = **3,000,000 บาท** (ไม่เกินเพดาน 5,000,000)
- ผู้ยื่นสมทบ (private match) ไม่น้อยกว่า 25% = **1,000,000 บาท**

## 6. แผนสมทบ (private match) — ต้องตัดสินใจ

| แหล่ง | จำนวน (สมมติ) | สถานะ |
|---|---:|---|
| ทุนจดทะเบียนของบริษัทที่ผู้ถือหุ้นไทยจ่ายจริง | ยังไม่กำหนด | ต้องยืนยันว่ามีเงินจริง |
| ค่าใช้จ่ายจากบริษัทพาร์ตเนอร์/สหกรณ์ (เงินสด) | ยังไม่กำหนด | ยังไม่มีข้อตกลง |
| แรงงานหรือทรัพย์สินที่ให้เป็นสิ่งสมทบ (in-kind) | ยังไม่กำหนด | **ยังไม่ยืนยันว่า NIA รับ in-kind หรือไม่** และต้องมีวิธีประเมินมูลค่า |
| รายได้จากสมาชิกหรือ EEC-SDG prize | ไม่นับ | เงื่อนไข prize ยังไม่ได้ตรวจ; ไม่ควรใช้เป็นสมทบจนกว่าจะยืนยัน |

ถ้าไม่มีแหล่งเงินสดรวม 1,000,000 บาท ให้ลดงบรวม: ทุกๆ 1 บาทที่ลดลง NIA สนับสนุนลดด้วย 75 สตางค์ และ private match ลดด้วย 25 สตางค์ (รักษาสัดส่วนไว้)

ตัวอย่างการลดงบ: ถ้าจ่ายสมทบเงินสดได้ 400,000 บาท → มูลค่าโครงการสูงสุด 1,600,000 บาท → NIA สนับสนุน 1,200,000 บาท

## 7. ความเสี่ยงที่ต้องเปิดเผยในข้อเสนอ

1. **ไม่มีบริษัท** — ผู้สมัครเป็นบุคคลธรรมดาไม่ได้ ต้องจดทะเบียนก่อน และรอบนี้ปิด 15 ธ.ค. 2569 (ประมาณ 7 สัปดาห์นับจากวันนี้)
2. **ประสบการณ์ 3 ปี** — บริษัทใหม่ไม่มีประสบการณ์เอง ต้องให้กรรมการหรือบุคคลที่มีประวัติมาแสดง ถ้าไม่มีต้องหาผู้ถือหุ้นหรือกรรมการที่ตรงเกณฑ์
3. **ข้อมูลจำลอง** — ระบบยังมีข้อมูลจำลองบางส่วน ต้องแจ้งและมีแผนแทนที่
4. **ข้อบกพร่องสภาพอากาศ** — ต้องแก้ก่อนทดสอบ
5. **ลิขสิทธิ์ข้อมูล** — ชุดข้อมูลบางชุดจาก data.go.th ใช้สัญญาอนุญาตที่ยังไม่ชัด (ดู `company-setup-pack.md` หัวข้อ 8) ต้องระบุแหล่งและไม่เผยแพร่ข้อมูลดิบโดยไม่ตรวจสอบ
6. **ความเป็นไปได้ทางเศรษฐกิจของการลงทุนสมทบ** — ผู้ยื่นต้องมีเงินสมทบจริง

## 8. สิ่งที่ผู้ใช้ต้องทำเอง (ห้ามทำแทน)

- จดทะเบียนบริษัทและกรอกชื่อ ที่อยู่ ทุนจดทะเบียน ผู้ถือหุ้น และเลขประจำตัวผู้เสียภาษี
- ยืนยันว่าเป็นผู้ถือหุ้นไทย ≥51% และมีประสบการณ์ ≥3 ปี หรือหาบุคคลที่ตรงเกณฑ์
- เลือกและยืนยันสาขา (แนะนำ #2) และงบประมาณ
- ลงนามข้อตกลงโอน IP (`ip-assignment-draft.md`) ก่อนยื่น
- เข้าสู่ระบบ mis.nia.or.th และกดยื่นเองทุกครั้ง โดยต้องได้รับอนุมัติจากคุณในแชทก่อนทุกการส่ง

## 9. ขั้นตอนถัดไปที่แนะนำ (ก่อนปิด 15 ธ.ค. 2569)

1. จดทะเบียนบริษัท (รวมวันที่: ประมาณ 1–3 สัปดาห์ ต้องยืนยันกับ DBD/ผู้สอบบัญชี)
2. ขอเอกสารแนวทางสาขา #2 เต็มจาก NIA (ติดต่อ 087-563-2074 หรือ mandatory@nia.or.th) เพื่อยืนยันเกณฑ์และการนับ private match
3. ขอใบเสนอราคาจริงสำหรับรายการงบ 1–7
4. ยืนยันการ์ดสมทบ 1,000,000 บาท หรือปรับงบ
5. แก้ engine สภาพอากาศและเปลี่ยนข้อมูลจำลองเป็นจริงอย่างน้อย 3 พืช
